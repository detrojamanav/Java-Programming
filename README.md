## 🧠 OOP Concepts Practiced

### 🔹 Encapsulation

Using private fields with constructors and methods to control access to object data.

### 🔹 Inheritance

Creating specialized classes from a common parent class.

### 🔹 Abstraction

Using abstract classes and abstract methods to define common behavior.

### 🔹 Polymorphism

Using a parent-class reference to work with different child-class objects.

### 🔹 Method Overriding

Providing specific implementations of methods in child classes.

### 🔹 Constructors

Initializing objects using parameterized and chained constructors.

### 🔹 Static Members

Sharing data and methods between objects using `static`.

### 🔹 Object Comparison

Implementing:

```java
equals()
hashCode()
toString()
```

to properly compare and represent objects.

## ▶️ How to Run

Make sure Java is installed on your computer.

Check your Java version:

```bash
java --version
```

Compile a program:

```bash
javac Driver.java
```

Run it:

```bash
java Driver
```

For programs with a different main class:

```bash
javac VendingMachine.java
java VendingMachine
```
